# Публичная EVA

На Windows-хосте работает production-сборка React, FastAPI, локальная Qwen3.5-9B-Kazakh и Whisper small. Временный HTTPS-адрес выдаёт Cloudflare Quick Tunnel. Адрес действует, пока запущен тоннель и доступен компьютер. Новый тоннель получает новое имя. [Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)

## Повторный запуск

Из корня EVA на текущем компьютере выполните:

```powershell
.\tools\start-public.ps1 -EnginePort 59174
```

Скрипт собирает frontend для запросов на том же HTTPS-адресе, проверяет сервисы, запускает недостающие и выводит рабочую ссылку. Если готовый процесс llama.cpp отсутствует, опустите `-EnginePort` и ML загрузит модель самостоятельно. Ему нужны локальные веса и исполняемый файл по путям из `ml/eva_ml/engine.py` или переменных `EVA_ISSAI_GGUF` и `EVA_LLAMA_SERVER`. Для Whisper используются веса в `ml/artifacts/models/whisper-small` и окружение `ml/asr/.venv`.

Для нового компьютера установите frontend-зависимости (`npm ci` в `frontend`), Python-зависимости Backend и ML в `ml/.venv`, затем окружение Whisper по инструкции. Скопируйте локальный архив профиля v7 с ожидаемым хешем и укажите его путь через `-Archive`. Для запуска тоннеля укажите официальный `cloudflared.exe` через `-Cloudflared` или положите его в `backend/data/public-tools/cloudflared-windows-amd64.exe`. [Распознавание речи](../ml/asr/README.md) · [Сборки cloudflared](https://github.com/cloudflare/cloudflared/releases)

## Данные и доступ

Наружу направлен только порт шлюза `127.0.0.1:18720`. Модель на `18721` и ASR на `18602` принимают локальные запросы. Шлюз создаёт отдельную SQLite и каталог аудио для каждого посетителя. В новом пространстве есть базовый чек-лист Freedom. Командные диалоги и записи из локальной БД там отсутствуют.

История сохраняется в том же браузере по подписанному HTTPS-cookie сроком на 30 дней. При очистке cookies, смене браузера или адреса тоннеля откроется новое пространство. Чтобы перенести транскрипт, откройте «Аудиозаписи», выберите запись и нажмите «Скачать JSON». Через «Диалоги» → «Новый диалог» этот файл можно загрузить снова.

В карточке диалога доступны удаление всей его истории и удаление одной оценки. Исходная аудиозапись остаётся в истории распознавания. В разделе «Чек-листы» можно убрать выбранную версию из списка для новых оценок. Действующие результаты сохраняют снимок прежней версии. Базовая версия Freedom доступна всегда.

Файлы стенда лежат в игнорируемом каталоге `backend/data/public-workspaces/`. Сохраняйте весь каталог вместе с ключом сессий и аудиофайлами в защищённой резервной копии. Для согласованной файловой копии остановите шлюз или используйте SQLite Backup API. Каталог `backend/data/public-tools/` содержит журналы служб. Публичный стенд рассчитан на одну GPU, до 24 одновременно открытых пространств, 128 сохранённых и 128 МиБ на пространство. Тяжёлые запросы оценки обслуживаются через общую очередь.

## Проверка и остановка

Из корня запустите проверку с публичным адресом. Она создаёт две новые сессии, оценивает синтетический чат, проверяет изоляцию и удаление. Параметр `--audio` принимает синтетический WAV с английской речью для проверки Whisper, скачивания JSON, повторного импорта и оценки звонка.

```powershell
ml/.venv/Scripts/python.exe tools/smoke_public.py https://PUBLIC_HOST --audio путь-к-тестовому.wav
```

Чтобы снять публикацию, завершите процесс `cloudflared`, запущенный для порта `18720`. Данные останутся на диске. Для постоянного адреса перенесите шлюз, модели и каталог данных на постоянно работающий хост и направьте на шлюз управляемый HTTPS-домен. Текущий стенд использует анонимные браузерные пространства. Командные аккаунты, распределение ролей и гарантированная доступность потребуют отдельной настройки.
