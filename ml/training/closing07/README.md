# Адаптер Qwen для C07

Это отдельный эксперимент для критерия «Завершение». Пример для обучения содержит исходный контекст клиента из очищенной части development и новую концовку с известной меткой. Старые оценки, эвристические признаки из CSV и ссылки на аудио не входят в запрос. [Доэкспериментальный протокол](PROTOCOL.md).

В каждом запросе Qwen выбирает один из трёх токенов. Для двух независимых разностей исходных logits обучаются шесть коэффициентов по кросс-энтропии. Они задают физическое изменение матрицы вывода: две строки фактора A равны разностям исходных строк проекции токенов A−C и B−C; три ненулевые строки фактора B содержат обученные коэффициенты. При ранге 2 и alpha=2 произведение этих факторов даёт поправку к трём logits. Остальная часть Qwen заморожена. Артефакт предназначен для указанного в протоколе запроса C07 и конкретного базового GGUF.

Команды из ml, PowerShell. Проверено на локальном Python 3.12. Нужны обычная Qwen3.5-9B Q5_K_M, llama.cpp и отдельный loopback-worker. Локальные зависимости эксперимента устанавливаются через requirements.txt этой папки.

~~~powershell
.\.venv\Scripts\python.exe -m pip install -r training/closing07/requirements.txt
$weights='D:/EVA-ML/models/Qwen3.5-9B-Q5_K_M.gguf'
$run='data/c07-training-repeat'
.\.venv\Scripts\python.exe -m training.closing07.experiment collect --port 59231 --out $run
.\.venv\Scripts\python.exe -m training.closing07.experiment fit --weights $weights --out $run
~~~

Запустите отдельный экземпляр того же llama.cpp с тем же GGUF и параметрами, добавив параметры ниже. Не останавливайте работающий сервис коллег; номера портов относятся к выделенному экспериментальному экземпляру. Число слоёв на GPU подбирается под свободную память.

~~~powershell
$adapter=(Resolve-Path "$run/closing07-r2.gguf").Path
# Дополнительные параметры worker: --lora $adapter --lora-init-without-apply
.\.venv\Scripts\python.exe -m training.closing07.experiment verify --port 59232 --out $run
.\.venv\Scripts\python.exe -m training.closing07.evaluate --out $run
~~~

verify проверяет путь загруженного адаптера и включает его со шкалой 1 для запросов C07. evaluate сравнивает реальные выходы, теоретическое действие факторов, ошибки с N/A и результаты прежнего конвейера на публичных синтетических диалогах. Пересчёт всех восьми критериев в отчёте — диагностическая подстановка C07 с семью прежними решениями. Для интеграции в основной оценщик отдельно нужны проверенные ссылки на реплики и обработка неопределённого входа.

Для воспроизведения на другом ПК требуются очищенный пакет и список development из [локальной подготовки DEV](../../CLEAN_DEV_COMPARISON.md), публичные наборы и прежние расчёты обычной Qwen из [исследования моделей](../../audit/LEDGER_RESULTS.md). Служебные файлы before.jsonl и after.jsonl содержат хэши примеров и вероятности, без исходной переписки.
