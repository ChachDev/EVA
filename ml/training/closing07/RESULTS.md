# Проверка очищенного DEV и обучение Qwen

Исходные шесть файлов из Downloads совпали по SHA-256 с локальным пакетом EVA. Сверка с первоначальным экспортом подтвердила 65/65 ID и все 1 268 текстов, ролей и позиций. CSV содержит 65 сводок, JSONL — 1 268 реплик. Они представляют один корпус. Все записи прошли приложенную JSON Schema и преобразование в контракт ML. В наборе 30 RU, 15 KZ и 15 EN чатов и пять русских транскриптов звонков. OpenAPI описывает четыре операции чтения; для обучения использованы локальные файлы. [Сверка пакета](../../data/c07-training-final/package-audit.json) · [Описание первоначального сравнения](../../CLEAN_DEV_COMPARISON.md).

В приложениях нет экспертных оценок по восьми критериям. resolved_guess истинен в 54 из 65 диалогов. Как минимум один quality_flags есть у 19. Девять abrupt-событий делятся на пять закрытий оператором и четыре ухода клиента или потери связи. Для критерия «Завершение» это существенное различие: возможность попрощаться определяется по последовательности реплик. Поле identity_verified отмечено у четырёх разговоров и подтверждено системными сообщениями, но даже для идентификации важно время события относительно раскрытия данных. Метаданные полезны для отбора примеров на разметку.

В проекте есть отдельный файл на девять development-чатов и 72 прежних решения, полученных из арбитража ИИ. В этом опыте из файла использованы только ID для выбора источников. Оценки в нём не использовались как обучающие ответы.

Для эксперимента взята **обычная Qwen3.5-9B Q5_K_M**, SHA-256 dc2a39aef291f91a9116ad214058da0d86eb648743a124bd8c333787c4b9c91c. Задача — C07, где можно задать ответ конструкцией концовки. Из разговоров ранее выделенной части разработки использованы только начальные реплики до первого оператора. Для каждого источника составлены по две концовки на «Да», «Нет» и «N/A». Тренировочные и проверочные контексты относятся к разным семействам. Пакеты из 38 кандидатов на независимую разметку и слепых 12 не пересекаются с источниками этих примеров. Пять звонков из очищенного DEV в тренировку не входили. [Протокол](PROTOCOL.md).

Обучаемые параметры — шесть чисел. Они изменяют три токена ответа через адаптер выходного слоя ранга 2. Остальная матрица Qwen заморожена. Подгонка не использует прежние баллы EVA, слабые флаги или оценки публичных серий. На 36 учебных примерах кросс-энтропия снизилась с 0,864 до 0,498; число точных ответов осталось 24/36. Публичные тесты уже знакомы проекту и подходят для диагностики переноса. Для решения о выпуске нужны новые человеческие оценки с ID реплик.

## Реальный результат переключения адаптера

Один экземпляр llama.cpp b12186 с одинаковыми весами, запросами и настройками оценил 44 проверочных разговора сначала со шкалой адаптера 0, затем со шкалой 1. Ни один вход не был усечён. Все 44 предсказания загруженного адаптера совпали с расчётом его матричного действия на отключённом варианте; максимальное различие центрированных logits на каждой серии округляется до 0,0000.

| Только C07 | Без LoRA | С LoRA | Исправлено / испорчено |
|---|---:|---:|---:|
| 18 новых контролируемых концовок | 12/18 | 12/18 | 0 / 0 |
| 10 публичных синтетических диалогов | 9/10 | 10/10 | 1 / 0 |
| 16 других публичных синтетических диалогов | 12/16 | 14/16 | 2 / 0 |

Три исправления — русские диалоги, где эталон «Нет», а исходная модель дала «Да». На новых контролируемых концовках тот же тип решения остаётся слабым: из шести ожидаемых «Нет» модель и до, и после не выбрала ни одного. По четыре из шести верных на каждом языке. Число ложных N/A не изменилось ни в одной серии.

Если заменить только C07 в сохранённых ответах основного конвейера, на публичной десятке получилось бы **72/80 вместо 71/80**, 10/10 итогов, MAE **9,200** вместо **9,969**. На второй серии получилось бы **105/128 вместо 103/128**, по 15/16 итогов, но MAE **9,098** вместо **8,664** на 15 общих чатах. Это офлайн-подстановка одной метки, а не результат обновлённого продукта. Рекомендация — оставить адаптер экспериментальным, подтвердить границу «Нет» у разметчиков и проверить место возникновения ошибки по репликам.
