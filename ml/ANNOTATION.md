# Разметка пилотной выборки DEV

[Рабочая книга](data/DEV-annotation-pilot.xlsx) лежит в локальном игнорируемом каталоге `ml/data/`. В ней есть тексты выбранных синтетических чатов, исходный порядок и время реплик. Файл открывается без доступа к API и доступен только там, где сохранена его локальная копия.

## Выборка

По четыре синтетических чата на язык для первой настройки. Внутри каждого языка чаты упорядочены по числу реплик, при равенстве длины — по детерминированному хэшу ID. Взяты позиции около 0, 33, 67 и 100 процентов ряда. Решения по критериям в отборе не использовались. Звонки и контрольные транскрипты в эту выборку не входят.

| Язык | Диалоги DEV и число реплик |
|---|---|
| Русский | `p1-ru-025` (11), `p1-ru-008` (14), `p1-ru-011` (14), `p1-ru-010` (32) |
| Казахский | `p1-kz-001` (12), `p1-kz-008` (13), `p1-kz-011` (14), `p1-kz-003` (26) |
| Английский | `p1-en-003` (12), `p1-en-009` (12), `p1-en-005` (14), `p1-en-006` (30) |

## Работа эксперта

1. Сохраните отдельную копию книги для каждого эксперта. На листе «Реплики» найдите разговор по полному ID и прочитайте его целиком. В качестве идентификатора реплики используется её позиция в исходном массиве, начиная с `m0001`. Нумерация включает бота и системные события.
2. На листе «Разметка» заполните восемь строк для этого диалога. Укажите оценку из списка, короткое объяснение и хотя бы один ID реплики. Для пропуска укажите участок, где действие ожидалось. Для нескольких несмежных реплик есть второе поле и свободное поле дополнительных ID.
3. Лист «Критерии» содержит правила и веса из [чек-листа Freedom CQA v1](../contracts/examples/checklist.json). N/A требует конкретного условия неприменимости. «На проверку» означает, что не хватает фактов для решения. Для грубых ошибок «Да» означает обнаруженное нарушение. Действия клиента и бота не приписываются оператору.
4. После двух независимых проходов сравните решения по паре «ID диалога + критерий». Сохраните обе исходные копии. Расхождения разбирайте по указанным репликам и фиксируйте согласованный ответ, причину и доказательства в третьей копии. Выборка предназначена для настройки, поэтому для итоговой проверки понадобятся другие диалоги.

## Инструменты для следующего этапа

- **Label Studio** пригодится, когда понадобится интерфейс для нескольких экспертов. В опубликованном шаблоне многоходового диалога роль и текст каждой реплики отображаются вместе, а вопросы разметки можно связать с конкретным участком. [Шаблон Multi-Turn Chat Evaluation](https://labelstud.io/templates/multi_turn_chat)
- **Модели** стоит сравнить после независимой разметки. Первый кандидат — казахская адаптация ISSAI Qwen3.5-9B, контрольный вариант — исходная Qwen3.5-9B. Оба получают один и тот же транскрипт и чек-лист. Более крупную ISSAI Qwen3.5-35B-A3B-Kazakh можно проверить отдельно при наличии подходящего оборудования. Ни одна из трёх моделей пока не измерялась на этой выборке. [ISSAI 9B](https://huggingface.co/issai/Qwen3.5-9B-Kazakh) · [Qwen 9B](https://huggingface.co/Qwen/Qwen3.5-9B) · [ISSAI 35B-A3B](https://huggingface.co/issai/Qwen3.5-35B-A3B-Kazakh)
