# EVA — Expert Virtual Auditor

Интерактивный дизайн-концепт для Freedom Broker.

## Запуск

Установите Node.js 22.13 или новее, затем выполните:

    npm install
    npm run dev

Для production-сборки:

    npm run build

## Что внутри

- src/ — React + TypeScript: обзор, диалоги, аудит с доказательствами, апелляции, редактор чек-листа, дизайн-система.
- public/brand/ — оригинальные SVG: знак EVA, логотип с подписью и графика сигнала.
- public/fonts/ — локальные Open Sans и лицензия.
- src/globals.css — все стили и адаптивные правила.

## Демонстрационные сценарии

Откройте DEMO-RU-001. Нажмите на доказательство, чтобы подсветить реплику. В критерии «Завершение» откройте апелляцию, выберите «Да» и укажите причину: итог изменится с 87,50 до 93,75.

Поиск, фильтры, редактор чек-листов, создание и рассмотрение апелляций, CSV/JSON-экспорт и просмотр загруженных транскриптов работают локально в браузере. Изменения сохраняются в localStorage. Новые версии чек-листа не изменяют прежние оценки.

Все исходные имена, разговоры и баллы вымышлены. AI-модель, API организаторов, CRM и запись звонков не подключены. Импорт файла не запускает автоматическое оценивание.

Кнопка «Файлы дизайна» в переносимой копии скачивает компактный набор SVG-ассетов EVA_Brand_Assets.zip, который также включён в public/downloads.

Это самостоятельный концепт для хакатона, не официальный утверждённый интерфейс Freedom.
