# EVA · Frontend

Новый интерфейс основан на предоставленном `EVA_Design_Kit.zip`: React, TypeScript, Vite, локальные шрифты Open Sans и SVG-иконки Lucide. Исходное описание набора сохранено в [design/EVA_DESIGN_KIT_SOURCE.md](design/EVA_DESIGN_KIT_SOURCE.md).

## Локальный запуск

Нужен Node.js 22.12+. Из `frontend/`:

```powershell
npm ci
npm run dev
```

Приложение открывается на http://127.0.0.1:5173/. Старый адрес `/eva-preview.html` перенаправляет на него, сохраняя раздел после `#`. Vite слушает только loopback; фиксированный порт не позволяет случайно занять порт другого сервиса. Для этой версии `.env.local` не требуется.

```powershell
npm run build
npm run preview
```

Сборка включает строгую проверку TypeScript. Предпросмотр сборки — http://127.0.0.1:4173/.

## Экраны и действия

- `#/overview` — показатели, динамика качества и последние диалоги.
- `#/dialogs` — поиск, фильтры по языку/каналу/статусу, CSV-экспорт.
- `#/dialogs/<id>` — транскрипт, оценка по критериям, переход к доказательству, JSON-экспорт и апелляция.
- `#/checklists` — редактор критериев и версий; прежние оценки используют собственный снимок чек-листа.
- `#/appeals` — рассмотрение апелляций с причиной решения и сравнением итогов.
- `#/brand` — палитра, типографика и локальные файлы дизайна.

Новый диалог принимает JSON или TXT до 2 МБ и 10 000 реплик. JSON поддерживает массив реплик либо `transcript` (также первый объект `records`/`data.records`). Поля реплик: `text`, `role`/`speaker`, `time`/`timestamp`. Допустимые роли: operator, client, system, bot. Импортированный транскрипт остаётся **без оценки**, хранится только в памяти вкладки и исчезает после перезагрузки. В сеть он не отправляется.

Изменения демонстрационных чек-листов и апелляций сохраняются в `localStorage` под ключом `eva-freedom-demo-v1`. Повреждённое сохранение сбрасывается с уведомлением. В разделе «Помощь и о проекте» есть «Сбросить демо и очистить импорт».

## Границы этой версии

Это **локальный интерактивный дизайн-прототип**, не подключённый к Backend или ML. Все исходные имена, разговоры и баллы — синтетические. Изменение оценки при рассмотрении апелляции иллюстрирует сценарий в браузере и не является серверным решением. Автоматического анализа, аудиоплеера, тёмной темы и переключения языка интерфейса в предоставленном наборе нет; RU/KZ/EN сейчас обозначают язык диалога.

`src/api/` сохранён для дальнейшей интеграции, но новый интерфейс его пока не вызывает. Переменные `VITE_API_MODE` и `VITE_API_URL` не переключают этот прототип в рабочий серверный режим. При интеграции итог должен поступать от Backend по [общим контрактам](../contracts/README.md); расчёт демонстрационного набора нельзя использовать вместо серверной оценки.

## Структура

- `src/App.tsx` — разделы, маршруты, локальные сценарии и импорт/экспорт.
- `src/eva-data.ts` — вымышленные примеры и расчёт демонстрационных баллов.
- `src/eva-detail.tsx`, `src/eva-ui.tsx` — разбор и общие элементы.
- `src/eva-storage.ts` — проверка данных браузерного хранилища.
- `src/globals.css` — стили набора, ограниченные `#eva-root`; reduced motion сохранён.
- `public/brand`, `public/fonts`, `public/downloads` — локальные ресурсы набора.

Прежний интерфейс сохранён в локальной игнорируемой резервной копии `artifacts/frontend-before-design-kit-*.zip`; старые дизайн-пробы остаются в `design/`. Работа ведётся в `main`, без автоматического commit, push или публикации.
